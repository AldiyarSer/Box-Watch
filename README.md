# Box Shape Integrity Classifier (Хакатон - тестовое задание)

Простой CV-агент, который определяет наличие дефекта у коробки по одному фото. 

## Логика работы
Модель не использует тяжелых нейросетей. Анализ проводится алгоритмами классического компьютерного зрения:
1. Изображение переводится в градации серого.
2. Выделяются границы объекта (Canny).
3. Извлекается самый крупный контур.
4. Происходит аппроксимация углов. **Если у объекта строго 4 угла — он сохранил форму прямоугольника/квадрата (OK). Если углов больше/меньше — коробка помята или деформирована (DEFECT).**

## Стек

- OpenCV (`opencv-python`)
- NumPy
